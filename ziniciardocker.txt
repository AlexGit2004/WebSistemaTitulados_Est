 Guía Completa en Linux (Desde Cero: Instalación hasta Ejecución)
Aplica tanto para Ubuntu nativo en un servidor Linux como para Ubuntu en WSL2.

Paso 1: Instalar Docker y Docker Compose
Ejecuta en tu terminal bash:

bash
# 1. Actualizar repositorios e instalar paquetes base
sudo apt update && sudo apt install -y ca-certificates curl gnupg
# 2. Instalar Docker Engine y el plugin Docker Compose v2
sudo apt install -y docker.io docker-compose-v2
# 3. Dar permisos a tu usuario para usar docker sin 'sudo'
sudo usermod -aG docker $USER
# 4. Iniciar el servicio de Docker
# En WSL:
sudo service docker start
# En Linux nativo con systemd:
# sudo systemctl enable --now docker
# 5. Aplicar el nuevo grupo en tu sesión actual (o reiniciar la terminal)
newgrp docker
Verificar que responde sin permisos de root:

bash
docker --version
docker compose version
Paso 2: Ubicar el proyecto
bash
# Si estás en WSL:
cd /mnt/d/UMSA/7mo_Semestre/zlinux/1A_webtituladostest/Sistema/sistema1_5
# Si clonaste en Linux nativo:
# cd ~/sistema1_5
Paso 3: Construir y Levantar
bash
# Construir la imagen y arrancar contenedores en segundo plano
docker compose up -d --build
Paso 4: Inicializar Base de Datos y Datos
bash

# 1. Migraciones Drizzle (crea tablas, enums, índices)
# Migraciones limpias
docker compose exec app pnpm --config.verify-deps-before-run=false db:migrate

# 2. Seed inicial (administrador adm@gen.bo y datos base)
# Seed inicial limpio
docker compose exec app pnpm --config.verify-deps-before-run=false seed

# 3. Seed masivo (con los contenedores corriendo)
docker compose cp datos_prueba.csv app:/app/datos_prueba.csv
# Seed masivo limpio (con datos_prueba.csv copiado)
docker compose exec app pnpm --config.verify-deps-before-run=false seed:masivo

# 4. Volver a seed inicial despues del masivo
docker compose exec app pnpm --config.verify-deps-before-run=false seed -- --reset


Paso 5: Comprobar el Despliegue
bash
# Ver estado de salud de PostgreSQL y de la App
docker compose ps
# Probar la respuesta HTTP
curl -I http://localhost:3000
Entra con tu navegador en http://localhost:3000 (o la IP del servidor Linux si es remoto).

Paso 6: Apagar el sistema
bash
# Apagado normal (mantiene los datos guardados en el volumen de postgres)
docker compose down
# Apagado con borrado total de la base de datos (volver a foja cero)
docker compose down -v
